# El Oráculo de ENOM 1.0.0

Estas notas describen el contenido previsto para la publicación `1.0.0`. La
versión no se considerará publicada hasta completar la validación final, integrar
el pull request y crear la etiqueta y la GitHub Release correspondientes.

## Funciones principales

- Tiradas simples de dados habituales o personalizados.
- Tiradas combinadas de hasta 10 tipos y 1.000 dados en total.
- Filtros y subtotales independientes, con suma global opcional.
- Títulos editables, búsqueda y gestión del historial.
- Copia y repetición de tiradas simples o combinadas.
- Historial SQLite guardado junto a la aplicación portable.
- Interfaz validada en 1920 × 1080 y 1366 × 768 al 100 % de escala.

## Descargar y ejecutar

La publicación incluye una aplicación portable para Windows x64. Descargá
`El-Oraculo-de-ENOM-Windows.zip`, extraé todo su contenido en una carpeta con
permisos de escritura y ejecutá `El Oraculo de ENOM.exe`.

La aplicación necesita conservar juntos el ejecutable y la carpeta `_internal`.
No requiere instalación. Al iniciarse crea `datos/historial.db` junto a la
aplicación.

## Importante para usuarios de compilaciones experimentales

Antes de iniciar `1.0.0` por primera vez, retirá, archivá o eliminá el archivo
`datos/historial.db` creado por compilaciones experimentales anteriores. Ese
historial no es compatible con el esquema definitivo y no se migra
automáticamente. La aplicación creará una base nueva al volver a iniciarse.

## Archivos de la publicación

- `El-Oraculo-de-ENOM-Windows.zip`: aplicación portable.
- `El-Oraculo-de-ENOM-Windows.zip.sha256`: checksum del ZIP.
- `El-Oraculo-de-ENOM-Windows.sbom.cdx.json`: inventario CycloneDX de los
  componentes de ejecución.

Para verificar el ZIP desde PowerShell:

```powershell
$Expected = (Get-Content ".\El-Oraculo-de-ENOM-Windows.zip.sha256").Split()[0].ToLower()
$Actual = (Get-FileHash ".\El-Oraculo-de-ENOM-Windows.zip" -Algorithm SHA256).Hash.ToLower()
$Actual -eq $Expected
```

El resultado debe ser `True`.

## Compatibilidad comprobada

- Windows 10 Pro, versión 2009, compilación 19045, x64.
- Resoluciones 1920 × 1080 y 1366 × 768 al 100 % de escala.

## Limitación conocida: aplicación sin firma digital

El ejecutable `1.0.0` no posee firma Authenticode. Windows puede mostrar una
advertencia según la configuración y reputación del archivo. El SHA-256 permite
detectar si el ZIP descargado difiere del publicado, pero no reemplaza una firma
digital. Descargá los archivos únicamente desde la GitHub Release oficial del
proyecto.
