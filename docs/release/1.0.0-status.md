El entorno virtual persistente conservaba sus paquetes, pero había perdido el
enlace interno `.venv/bin/python3`; por ello los entry points no podían iniciar.
Se reparó el entorno ignorado por Git con `python3 -m venv --upgrade .venv` y se
verificaron estas versiones:

- Python `3.12.14`;
- PySide6 `6.11.2`;
- PyInstaller `6.22.2`;
- pytest `9.1.1`.

Esta reparación no modifica archivos versionados.
